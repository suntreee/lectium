# Lectium

Lectium is a small bookmarklet that turns public article pages into a calm reading view.

It works entirely on the current page: it extracts the most likely article content, removes common visual clutter, and opens the result in an overlay with dark mode, font sizing, and print support.

## Install

Open `index.html` in a desktop browser, then drag the **Lectium** button to the bookmarks bar.

If drag-and-drop is blocked, create a new bookmark manually and paste the generated `javascript:` URL from the text box into the bookmark URL field.

## Features

- Article extraction from the current page DOM
- Clean reading overlay without replacing the original page
- Dark mode
- Larger and smaller text controls
- Print-friendly layout
- No network requests and no remote dependencies

## Notes

Lectium is a reading aid for pages you can already access. It does not bypass logins, subscriptions, or server-side access controls.
